Color Masking

First we need to understand how a computer see's an image. At its core, an image is just a large array of numbers, representing the location and content of each pixel.

Images are stored in an array of (H, W, Chan_Vals)

Using code like this we can see what one of these arrays might look like 

  import cv2

  #Read the image (Open CV loads images in B,G,R color format)
  image_bgr = cv2.imread("cat.jpg")

  print(f"{image_bgr}")
        
  [[[202 196 183]
  [202 196 183]
  [202 196 183]
  ...
  [186 180 167]
  [186 180 167]
  [186 180 167]]

Note: Channel values are typically [R, G B] or [R, G, B, A], printout is truncated by OpenCV
