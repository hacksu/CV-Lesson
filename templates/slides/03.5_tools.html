What Is Computer Vision

Tools we Will Need

Open CV

Open source library that implements most computer vision tools we will need in both python and C++ 

uv init
uv add opencv-python

NumPy

Library for fast optimized python math. Useful for computer vision and working with OpenCV 

uv add numpy

Ultralytics

Library of models for object detection we will use later. 

uv add ultralytics

Media Pipe

Body landmark detection model we will use later. Get it from googles website or the install script.
