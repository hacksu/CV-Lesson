Types of Kernels

Gaussian Blur

Matrix with a Gaussian Distribution, can blur over an image reducing noise. Used to reduce noise and useful for other detection. 

[1, 2, 1]
[2, 4, 2]
[1, 2, 1]

Edge Detection

Values differences on either side of the kernel. If all values under the kernel are similar, final value trends to 0. 

[1   ,1   ,1]
[0,   0,   0]
[-1  ,-1 ,-1]

Sharpening

Enhances pixel intensity and visibly defines objects more. Empahsises value of the center pixel. 

[0, -1,  0]
[-1, 5, -1]
[0, -1,  0]
