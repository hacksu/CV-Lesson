Image Pre-Processing

Before we can extract meaning from an image, the computer needs to understand what is happening in the image. Because computers cannot percive an image, we need to process the raw pixels into an easier to work with form.

To accomplish this, we need to do image preprocessing, normalizing aspects of the image into a more workable form.

Note: This is for more typical non-ML and non LLM processing, LLM's are a confusing magic box we will talk about later
