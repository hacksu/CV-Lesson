04 - How Does CV Work

The Start of Machine Learning

Earlier approaches had to have pre-defined kernels that were fine tuned by hand to accurately detect where objects were. Machine Learning changed that by moving away from a single purpose kernel to a series of learned kernels working in tandem. This new model was dubbed Convolutional Neural Networks (CNN)

The Training Loop

To produce a computer vision model we start with random kernel weights and a labeled dataset. The model runs its kernels over the picture -> Measures the error (the loss) -> Adjusts the kernels to be closer -> Repeats. Do that enough and you get accurate kernels that understand what they are detecting.
