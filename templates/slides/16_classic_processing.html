Classical Processing

Features

A feature is a piece of information in an image that implies a point of interest. Features help classical CV tools detect objects in images without knowing what an image is.

Classical processing largely focuses on finding and describing features in an image. This is typically accomplished using kernels to analyze the contents of an image.

Kernels

A Kernel is a matrix of weights (typically 3x3) that slides over an image. At each pixel you sum pixel value * weight and assign that value to the center pixel. This allows you to describe changes in the image over a set of pixels.

Note: The process of moving a Kernel over an image is called convolution
